# Bounty Hunters phone app

Installable shell for the Florence Bounty Hunters phone board. It holds no data: it frames the
private Google Apps Script board, which only its owner can open after Google sign-in.

- **Android (Chrome):** open https://joshuatshirley.github.io/bounty-hunters-app/ → menu ⋮ → **Install app**.
- **iPhone (Safari):** open the board link, sign in, Share → **Add to Home Screen**.
